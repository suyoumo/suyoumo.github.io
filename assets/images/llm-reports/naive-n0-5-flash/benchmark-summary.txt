口径与来源说明（来自报告正文脚注）
1. MLE-bench-30 数值带百分号，入库时去掉 % 与榜单 mle_bench 既有条目保持一致。
2. ProgramBench 报告的是 Almost@1 口径。
3. FrontierSWE v1 用截至 2026-08-23 的竞品结果计算 Dominance 分。
4. DeepSWE v1.1 中 GPT-5.6-Sol 与 Opus-5 取自 DeepSWE v1.1 榜单，Opus-5.5 取自 Claude Opus 5.5 System Card。
5. SWE-Bench Pro 中 GPT-5.6-Sol、Opus-5、Opus-5.5 取自 GPT-5.6 博客与 Claude Opus 5.5 System Card。
6. PaperBench 中 MiniMax M3、Opus-4.7、GPT-5.5、Gemini-3.1-Pro 取自 MiniMax M3 模型页。
7. 评测配置：Claude Code 2.1.207，1M 上下文，temperature 1.0，top-p 0.95，基础文件读写与 Bash 工具。
8. 模型权重与推理栈以 MIT 许可开源，基座为开源 MiMo-V2.5。
