WHY THIS EXISTS

Games expose whether an agent can carry intent across time.

3DGameAgentBench evaluates agents building and revising interactive Three.js games through a sequence of user-driven requirements.

每一轮都要接住新要求，也要守住先前已成立的玩法、交互和状态。项目细节保持受限开放，参与者将直接帮助定义这一评测边界。

THE WORK

Long-horizon by design.

01

Build

从可玩的 Three.js 3D 游戏原型开始，建立可见、可操作的基础状态。

02

Change

连续追加、修改和撤销需求，让新旧系统在同一份游戏代码中真正发生耦合。

03

Verify

用明确可观察的行为复核每一轮，让长程生成不止停留在“看起来能跑”。
