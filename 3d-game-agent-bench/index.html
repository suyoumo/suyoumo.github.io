WHY THIS EXISTS

Games remember every change.

3DGameAgentBench evaluates agents as they build and revise an interactive Three.js game through a sequence of user requirements.

每一轮都要接住新要求，也要守住此前的玩法、交互与状态。公开目标很简单，benchmark 内部细节保持保密。

HOW IT WORKS

One game. Many rounds.

长程生成不是一次性 demo，而是在同一份游戏代码上持续演进。
